# Bimenes Vive

Bimenes Vive es una aplicación móvil que diseñada para el municipio de Bimenes, en Asturias.

La funcionalidad principal de la aplicación es dar una herramienta a los vecinos de Bimenes para
que puedan poner anuncios de venta o alquiler de propiedades inmobiliarias que estén en el municipio.

Cuenta con otras funcionalidades como la de un tablón de anuncios para que compradores puedan
manifestar su interés en comprar o alquilar propiedades y también una sección institucional donde
el ayuntamiento de Bimenes pueda publicar información de interés para los potenciales nuevos vecinos.

Utiliza Firebase Firestore para almacenar y recuperar datos, Coil para la carga de imágenes,
OpenStreetMap para guardar la localización y JUnit para realizar testing.
