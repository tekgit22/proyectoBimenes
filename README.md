# Bimenes Vive

Bimenes Vive es una aplicación móvil que proporciona información detallada sobre viviendas disponibles en la parroquia de Bimenes. Utiliza Firebase Firestore para almacenar y recuperar datos, Coil para la carga de imágenes y OpenStreetMap para la visualización de mapas.
